# Using the portable student pack

This pack includes a ready-made report for an interpretation session, plus quick-start
and practice guides for running the native executable without installing Python.

For a hands-on start, download the native build for your OS and follow `QUICKSTART.md`
at the root of this pack, then `docs/PRACTICE.md`. The same guides are included in each
v0.2.1 native archive. Download links are on the
[release page](https://github.com/ArgeliusLabs/DopplerLab/releases/tag/v0.2.1).

## Start in five minutes

Open `examples/report/report.html` in a browser, read `docs/STUDENT_LAB.md`, and work
through the prediction, evidence inspection and written assessment. The PNG figures
and CSV/JSON results can also be opened separately. The included audio and tracks are
fictional. The `truth.json` files and full instructor guide are omitted from this pack;
the short practice guide does include a clearly marked self-check for the same fixture.

To run new experiments, use the separate native executable; it bundles the runtime and
generates the practice data. This student pack itself contains no executable, Python
runtime or scientific dependencies. Python users can instead use the source release.
The core project and practice answers are public; this is not an answer-secure assessment
pack. Ask your instructor to provide controlled comparison reports
for the one-event, sound-speed and noise exercises if you cannot run the software.

Third-party video, audio and flight data are not included. The example report is
self-contained and makes no network requests. Its external credit link opens only
if you choose to follow it.
